I-4常用术语例如劳力性呼吸困难、活动耐量下降、低氧血症、颈静脉怒张；总结性术语例如左心容量超负荷、体液潴留、体循环淤血、心血管危险因素/疾病史。只接受与病例事实相符的表述；原表的示例词不是患者必有全部这些表现的证明。“心血管疾病史”可按原表分别支持危险因素及总结性术语两个不同类别，不把同一类别内重复提及多算分。

参考摘要：58岁女性，有冠状动脉疾病、高血压，慢性进行性咳嗽与劳力性呼吸困难，伴低氧、容量负荷异常及相应心肺检查发现。摘要只供核对，不能替学生补答。

### 2 D 主要诊断2分

只评价最终主要诊断字段，按Excel宽严与语义判定：

|  得分 | 判分条件及本例表达                                                               |
| --: | ----------------------------------------------------------------------- |
|   2 | 急性失代偿性心力衰竭；急性心衰；失代偿性心衰；慢性心力衰竭急性加重。原表为“急性、失代偿性、心衰”三关键词有两个，但须实际表达相应心衰诊断含义 |
|   1 | 心力衰竭/心衰、（全）心衰、慢性心力衰竭、心功能不全、（急性）左心衰竭等原表的部分正确表达；“急性心衰”按上一档2，不能与较窄的左心衰混为一条 |
|   0 | 未给主要诊断或明确错误，如肺心病、右心衰、COPD合并心功能不全等原表错误例                                  |

“非首要诊断”同时列在0分和1分示例中：正确心衰只出现在次要诊断且主诊断不同、会影响本次D时，待复核Q02。只写“急性失代偿”但病名及上下文含义不明确，不机械数两词给2分，见Q03。

### 3 E 主要诊断依据2分

从考生提交、对应主要诊断的支持点取证；不从系统结果或标准答案代填。按研究版0、1—2、3—5档给分。**现版暂按源表编号的五类去重计数，同一类多个发现只算一类；这是对计数单位的暂行解释，待核对Q01。**

| 类别 | 命中条件 任一正确表达即可 |
| --- | --- |
| E-1 体循环淤血体征 | 颈静脉怒张、肝颈静脉回流征阳性、下肢水肿中的任一实际阳性发现 |
| E-2 肺水肿症状体征 | 双肺啰音或低氧血症 |
| E-3 异常实验室结果 | 本次BNP/NT-proBNP升高，或转氨酶升高/肝功能异常 |
| E-4 影像/相关检查 | 胸片肺淤血、胸腔积液、心肺运动试验显示的相应异常结果之一；只列检查名称不证明取得了支持性结果 |
| E-5 心尖区体征 | 心尖区杂音 |

| 正确的不同类别数 | E得分 |
| ---: | ---: |
| 0 | 0 |
| 1—2 | 1 |
| 3—5 | 2 |

例如只写颈静脉怒张、回流征阳性、下肢水肿，暂按一类，E=1；写颈静脉怒张、双肺啰音、NT-proBNP升高，命中三类，E=2。类别数用于查档，不与旧的6/5/5等项目分混加。错误事实、未开展的计划或明确用于否定主诊断的内容不作为正确依据；同类里其他独立正确发现仍可核对，不额外整类扣分。

## 六 治疗方案可行性2分

采用研究版A=Assessment & treatment。联合读取诊疗计划、治疗方案，按下列五类去重：

| 类别 | 正确方案要点 |
| --- | --- |
| A-1 一般处理 | 限钠/低盐、限水、吸氧；暂按源表“/表示或”接受任一正确措施，同类多项仍只算一类，待核对Q06 |
| A-2 利尿 | 明确提出利尿，或源表的呋塞米；仅写“醛固酮”的药物身份不明确，见Q06，不自动改成其他药 |
| A-3 改善心肌代谢 | SGLT2抑制剂 |
| A-4 β受体阻滞剂 | 明确提出该类或已批准的同类药名 |
| A-5 ACEI/ARB/ARNI | 任一类正确即可，同类多项仍只算一类 |

| 正确的不同方案类别数 | A得分 |
| ---: | ---: |
| 0 | 0 |
| 1—2 | 1 |
| 3—5 | 2 |

“低盐＋限水”只属于一般处理一类，A=1；“低盐＋利尿”为两类，仍A=1；再提出SGLT2抑制剂，达到三类，A=2。不再给每类2分，也不沿用旧的一般处理内部0/1/2档。

不在附件之外增加剂量、时机、禁忌证等隐藏分值。明确风险或条件性暂缓但标准未规定时记录具体问题供专家核对；原有用药、明确停药或只有笼统治疗目标不自动算提出措施。某未知类别不改变本次分档时可确定A，若改变分档才待复核。

## 七 检查项目分中的结果分析依据

本节为第二、三节的项目分析部分提供判读依据，按通用规则“关键发现P/4＋临床意义P/4”计入相应项目分，不另设分析总分。下表两个判读条件分别对应这两部分；同一部分要求多个必要信息时须全部正确。数值可用准确的升高/正常/降低概括，不必照抄全部数字。

以下16项判读参考仍为医学教师待确认的初稿（Q07）。前13项对应有项目分的检查；末3项腹壁视诊、生命体征、甲状腺功能仅给文字反馈，不新增分数或改变两维满分。

| 检查项目 | 关键发现给分条件 | 临床意义给分条件 | 典型错误示例 |
| --- | --- | --- | --- |
| 心脏听诊 | 心尖收缩期杂音及额外心音 | 提示瓣膜/心功能异常，结合本病例支持心衰 | 把杂音及额外心音均说成不存在 |
| 双肺听诊 | 双下肺粗湿啰音 | 提示肺淤血/肺水肿可能 | 说肺部完全正常而否定存在啰音 |
| 颈静脉充盈检查 | 颈静脉充盈增高 | 提示静脉压增高/体循环淤血 | 把明确充盈增高说成无充盈 |
| 肝颈静脉回流征 | 肝颈静脉回流征阳性 | 提示体循环静脉淤血 | 把阳性判成阴性并据此否定淤血 |
| 下肢水肿检查 | 双侧踝部凹陷性水肿 | 提示液体潴留/体循环淤血 | 说无水肿且无液体潴留 |
| NT-proBNP | NT-proBNP1020，相对本病例参考范围升高 | 支持心衰，不能据单项独立确诊 | 说指标降低，因而排除心衰 |
| 胸部X线 | 存在肺淤血性影像改变 | 结合症状支持肺水肿/心衰 | 说胸片肺部正常且无淤血 |
| 动脉血气 | PaO₂59，氧分压降低 | 低氧血症；本次PaCO₂正常，不支持二氧化碳潴留 | 说氧分压正常、没有低氧 |
| 心电图 | 窦性心律及所列导联T波变平 | 存在T波改变，病因需结合其他检查判断 | 杜撰本报告未提供的ST段抬高并确诊急性心梗 |
| 血生化 | 肌酐1.8，超过给定上限1.4 | 提示肾功能异常，结合既往慢性肾病 | 把肌酐判断为正常或降低且肾功能无异常 |
| 血常规 | 主要血常规指标处于本病例给定范围 | 未见明显贫血或白细胞增多的依据 | 说血红蛋白降低，已经证明明显贫血 |
| 肝功能 | AST50、ALT51超过给定上限 | 提示转氨酶升高/肝功能异常 | 说转氨酶均正常、未见肝功能异常 |
| 心肺运动试验 | 室内空气行走SpO₂降至83%，吸氧后96% | 活动时低氧，吸氧后氧合改善 | 说活动时氧合正常且吸氧无改善 |
| 腹壁视诊 | 右上腹约10cm手术瘢痕 | 提示既往手术，不能单凭瘢痕确定具体术式 | 说没有瘢痕，也无可见手术痕迹 |
| 生命体征 | 静息SpO₂90%，氧饱和度降低 | 存在氧合不足的表现，需要结合病因判断 | 说该血氧完全正常且无氧合问题 |
| 甲状腺功能 | TSH2.3，处于给定0.4至5.0范围 | 本次TSH未见明显异常；不扩展为排除所有甲状腺疾病 | 说TSH明显升高并据此判断甲减 |

末列说明错误类型，不额外扣项目分或整维分。关键发现正确、临床意义错误，只得关键发现的P/4；错误发现导致错误意义，分析两部分均0。开展分按是否取得对应结果保留。

血气的核心发现为低氧分压，意义为低氧血症；本次PaCO₂处于给定范围，若另写二氧化碳潴留属于解释错误，该意义分0。没有要求学生在每项分析都重复写“不能单独确诊”才能得分；只要给出适当的支持性解释且未作无依据的确定结论即可。

例如NT-proBNP项目满分7：开展3.5、关键发现1.75、临床意义1.75。取得结果但只写“升高”，项目5.25/7；再准确说明支持心衰，项目7/7；分析完全错误但确已开展，项目3.5/7。顺序最多3分另计，不包含在这7分内。未开展项目保留原满分并记0；结果或判读资料缺失影响该项目及所在维度，按通用规则处理待复核。

本例NT-proBNP使用原病例1020及其参考范围，只评价升高和诊断支持作用，不把参考上限误当急性心衰确诊阈值。核查背景：[AHA心衰诊断检查说明](https://www.heart.org/en/health-topics/heart-failure/diagnosing-heart-failure)。这份说明用于核对指标/检查的作用，不批准本表分值或替代本病例标准。
